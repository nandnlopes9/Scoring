## 💻 Executar localmente

Caso queira executar o projeto no próprio computador:

1. Configure um ambiente com PHP 8.1+ e MySQL/MariaDB.
2. Crie um banco de dados vazio chamado `scoring_demo`, utilizando a codificação `utf8mb4`.
3. Importe o arquivo `Banco de Dados/scoring.sql` pelo phpMyAdmin.
4. Copie `PHP/config.example.php` para `PHP/config.local.php` e preencha as informações de conexão com o banco.
5. Na raiz do projeto, execute:

```bash
php -S 127.0.0.1:8000
```

6. Abra `http://127.0.0.1:8000` no navegador.

O projeto também pode ser executado utilizando XAMPP.
